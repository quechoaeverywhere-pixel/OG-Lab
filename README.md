# ONENESS GOVERNANCE (OG LAB)
> **Slogan Cốt Lõi:** *Deep Research & Knowledge Transforming (Chuyển Hóa Tri Thức)*  
> **Nền tảng:** Web Application Nghiên cứu Đa ngành, Khảo luận Học thuật & Kiến trúc Multi-Agent Swarms.

---

## 1. Giới Thiệu & Sứ Mệnh Cốt Lõi

**Oneness Governance (OG Lab)** là không gian nghiên cứu học thuật cao cấp và chuyển hóa tri thức thế hệ mới. Ứng dụng giải quyết bài toán cốt lõi của thời đại AI:
- **Tri thức hàn lâm đã sẵn có trên các LLM**: Khối lượng tri thức khổng lồ về triết học, khoa học máy tính, lý thuyết hệ thống phức tạp và kinh tế học đã được lưu giữ trong các mô hình AI tiên tiến.
- **Sứ mệnh Knowledge Transforming**: Đóng vai trò là cỗ máy chuyển hóa tri thức — tiếp nhận, phân tích và đối soát ở tầm mức học thuật cao nhất, nhưng khi xuất bản báo cáo, toàn bộ nội dung được biên dịch sang **ngôn ngữ đời thường, trong sáng, gãy gọn và thực chiến**, giúp bất kỳ ai đọc vào cũng nắm được bản chất để hành động, vận động và kiến tạo giá trị cụ thể cho xã hội.

## 2. Bản Giao Ước 6 Trụ Cột Động

Kiến trúc nội dung của Oneness Governance vận hành theo **Giao Ước 6 Trụ Cột Động**, tự động thích ứng với từng chủ đề nghiên cứu:

| Trụ Cột | Tên Triết Học | Ý Nghĩa Hệ Thống |
| :--- | :--- | :--- |
| **Trụ Cột I** | *Bản Thể (Ontology)* | Ý niệm nguyên thủy, bản chất gốc rễ, đối chiếu triết học Đông - Tây và nguyên lý khởi nguyên. |
| **Trụ Cột II** | *Cơ Chế (Mechanism)* | Quy luật vận hành nội tại, động lực học hệ thống, dòng chảy thông tin/tài nguyên. |
| **Trụ Cột III** | *Kiến Trúc (Architecture)* | Ánh xạ sang Khoa học Máy tính (CS Parity), kiến trúc Multi-Agent Swarms, mã thực thi. |
| **Trụ Cột IV** | *Biện Chứng (Dialectics)* | Phản biện đa chiều, nghịch lý lịch sử, failure modes và cơ chế quản trị rủi ro. |
| **Trụ Cột V** | *Tĩnh Tâm (Shinbashira)* | Trọng tâm cân bằng đạo đức, khắc kỷ và an ninh bảo vệ hệ thống trước biến động. |
| **Trụ Cột VI** | *Đất Trời (Wu Wei)* | Vươn ra ngoài hòa hợp với hệ sinh thái tự nhiên, phát triển bền vững và nhân sinh. |

## 3. Kiến Trúc Phân Quyền Zero-Trust

Hệ thống triển khai ma trận bảo vệ dữ liệu công trình nghiên cứu:
- **4 Cấp Bậc Vai Trò (Roles)**:
  - `Guest`: Khách vãng lai chưa đăng nhập (Chế độ đọc tự do).
  - `Viewer`: Độc giả đã đăng nhập Google (Bảo vệ dữ liệu, tránh sửa ngoài ý muốn).
  - `Author`: Tác giả nghiên cứu (Mở khóa sinh bài AI, biên tập, tạo hồ sơ mới).
  - `Admin`: Tổng Quản Trị / Owner (`quechoa.everywhere@gmail.com` - Toàn quyền cấu hình bảo mật).
- **5 Quyền Hạn Nguyên Tử (Atomic Permissions)**: `compose_article`, `ai_research`, `create_dossier`, `manage_dossier`, `system_settings`.
- **Shinbashira Session Guard**: Cơ chế khóa màn hình bảo vệ phiên làm việc.
- **Content Edit Lock**: Công tắc khóa biên tập toàn cục do Tổng Quản Trị làm chủ.

## 4. Các Tính Năng Nổi Bật

1. **AI Deep Research Engine**: Khởi chạy khảo luận học thuật tức thì với Gemini 3.7 / Flash kết hợp Google Search Grounding.
2. **Publisher Studio 5 Phân Hệ**:
   - *Soạn Thảo Đa Phương Thức*: Trực quan hóa thẻ nguyên tử (Atomic Content Cards), trích dẫn, mã nguồn và bảng biểu.
   - *Sổ Từ Điển Thuật Ngữ (Lexicon Hub)*: Tự động trích xuất và giải nghĩa thuật ngữ chuyên ngành sang ngôn ngữ đời thường.
   - *Sổ Trích Dẫn Kinh Điển (Citations Library)*: Quản lý trích dẫn kinh điển Đông - Tây và whitepapers chuẩn IEEE/ACM.
   - *Phòng Thí Nghiệm Prompt & NotebookLM*: Xuất cấu trúc prompt nghiên cứu tương thích 100% với NotebookLM và LLM Studio.
   - *Tài Khoản & Quản Trị Bảo Mật*: Quản lý danh tính học giả, đổi vai trò kiểm thử và cấp phát mã tác giả.
3. **Chế Độ Trình Chiếu (Zen Presentation Mode)**: Trình diễn toàn màn hình bài khảo luận phục vụ hội thảo và thuyết trình chuyên môn.
4. **Đồng Bộ Google Drive & Sao Lưu 1-Click**: Tự động sao lưu và phục hồi toàn bộ kho hồ sơ ra file JSON chỉ với 1 cú click.

## 5. Hướng Dẫn Cài Đặt & Khởi Chạy

### Yêu Cầu Môi Trường
- Node.js 18+
- Biến môi trường: `GEMINI_API_KEY` (được cấu hình trong `.env` hoặc hệ thống quản lý secrets)

### Cài Đặt & Khởi Động
```bash
# Cài đặt các gói phụ thuộc
npm install

# Khởi chạy máy chủ phát triển (Express + Vite trên cổng 3000)
npm run dev

# Đóng gói sản phẩm (Production Build)
npm run build

# Khởi chạy máy chủ Production
npm start
```
